# Project Description

PetCare is a desktop-based management system developed for pet stores and animal care businesses. The system is implemented in Python using PySide6 for the graphical user interface and SQLite as the local database engine. It is designed to support the core operations of a pet retail and service business, including animal intake management, health monitoring, customer tracking, product inventory, sales, memberships, service scheduling, reporting, and alert management. The system follows a local-first architecture, requiring no separate backend server, no external cloud infrastructure, and no internet-dependent service layer for normal operations.

The main objective of the project is to integrate the major operational workflows of a pet business into a single application so that staff can manage data and tasks in a structured and efficient way. Pet data, customer records, financial transactions, stock information, membership status, service schedules, and operational logs are centralized in one database, improving consistency, reducing manual errors, and supporting faster decision-making. The system is particularly suitable for small and medium-sized pet stores, grooming centers, and animal care facilities that need a practical and affordable management platform without investing in large enterprise systems.

Functionally, the system supports pet profile management with detailed attributes, care and health tracking, intake documentation, supplier and inventory control, stock warning mechanisms, sales order processing, customer and membership management, and appointment scheduling. The recommendation module provides offline product suggestions based on pet profiles, stock availability, and user preferences, helping staff offer more relevant products and packages. In addition, the system includes reporting and audit features to improve operational transparency and accountability.

From a security perspective, the system implements password hashing with PBKDF2-HMAC-SHA256 and random salts, mandatory password changes for first-time admin login, role-based access control, and audit logging for critical actions. These mechanisms help protect sensitive business and customer information while improving the traceability of user actions. Although the system is designed for local deployment and does not expose public-facing web endpoints, it still requires strong machine security, restricted user access, and regular data backup to maintain reliability and confidentiality.

Overall, the proposed system provides a practical, scalable, and user-friendly platform for pet business management. It combines operational efficiency, data integrity, and security in a single local desktop environment, making it a suitable solution for small-scale pet businesses that need a low-cost but effective management tool. The project demonstrates the application of software engineering principles in building a real-world business information system with modular architecture, secure design, and domain-specific functionality.
