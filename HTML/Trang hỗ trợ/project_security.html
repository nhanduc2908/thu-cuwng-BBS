Security review

Security & data protection

This review summarizes the security controls currently implemented in the PetCare desktop application, the data-risk boundaries of a local-first deployment, and the operational safeguards still needed before real operational data is handled at scale.

01Scope & assumptions

3 pillars
Deployment Boundary

Local application boundary

PetCare operates as a local Windows application with SQLite storage. The security boundary includes the workstation, the configured user account, the database path, and the backup process.

Information Sensitive

Operational data sensitivity

Customer records, pet profiles, health notes, service history, transactions, and staff accounts may all be in scope. Data access should be proportional to task and role.

Threat model Defined

Not a SaaS model

This is a local-first review: it focuses on unauthorized access, account compromise, database exposure, backup loss, and internal process misuse—rather than cloud infrastructure or external hosting controls.

02Implemented controls

Live in production
Authentication Đã triển khai

Password hashing

Passwords are hashed using a salted, iterated PBKDF2 approach. This significantly reduces the impact of credential theft and helps protect stored credentials from offline guessing attacks.

auth/security.py
Authorization Đã triển khai

Role-based permissions

Permissions are separated by role so that administration, care, sales, and management functions are not shared equally. UI hiding is helpful, but the actual enforcement must remain at the business logic layer.

auth/constants.py
Auditability Đã triển khai

Change event logging

Audit logs record actor, action, entity, and timestamp for selected operational changes. This supports accountability and allows later review of critical workflows.

audit/repository.py
Access Khuyến nghị

Least privilege

Grant only the minimum role permissions needed per user. Review access regularly and remove stale rights when staff change tasks or exit the organization.

Recovery Khuyến nghị

Backup discipline

Maintain encrypted, versioned backups stored outside the active working directory and test a restore procedure on a non-production copy before relying on it for real operations.

Monitoring Cần rà soát

Operational review

Track suspicious pattern changes, failed sign-ins, database access anomalies, and unusual broad exports. This is especially important in shared local environments.
