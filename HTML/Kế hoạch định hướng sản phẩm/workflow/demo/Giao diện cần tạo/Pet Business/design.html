03 · VISUAL LANGUAGE

Design tokens & thành phần giao diện

Phong cách enterprise premium: gọn, rõ thứ bậc, có nhịp thở; màu là tín hiệu trạng thái chứ không thay nội dung.

Palette

Review#C48A26 · watch / awaiting
Exception#B94A45 · blocked / variance

Typography & spacing

Display / page title: Segoe UI, 28–34px, weight 750; one title per route.

Section: 16–20px, weight 700; sentence-case labels.

Body: 13–14px with 1.5 line height; table 12–13px.

Microcopy: 11–12px; use for metadata only, never critical instructions.

Spacing: 4 / 8 / 12 / 16 / 24 / 32px; card radius 12px; content max 1440px.

Core component states

Approved Confirmed terminal gate, actor/time displayed.

Pending Owner, SLA and next action shown.

Blocked Reason, missing evidence and remediation linked.

Read-only Source-of-truth and last-sync visible.

Table supports search, filters, sort, empty, loading, error and stale states.

Interaction rules

Primary action is singular and contextual; destructive/financial changes use confirm + reason.

Every action shows pending → accepted/rejected → committed; never success-shaped fallback.

Filters persist in URL/query where practical; selected branch and period remain visible.

Keyboard focus, labels, contrast and reduced-motion behavior are required.

06 · DELIVERY & DEFINITION OF DONE

Tiêu chí để đội phát triển bắt đầu code

Không coi một màn hình là hoàn tất chỉ vì dựng xong khung và bảng.

Data & permissionTenant isolation test; branch scope filter ở server; maker/checker không trùng; sensitive fields masked.
Workflow integrityState machine kiểm version; idempotent command; append-only correction; no negative stock; period lock enforced.
Operational UILoading/empty/error/stale states; table search/filter/sort/pagination; keyboard and mobile behavior tested.
Integration & auditContract tests; outbox retry/DLQ owner; reconciliation replay; audit links request, actor, decision, movement.
ObservabilityCorrelation ID; freshness; queue age/SLA; connector lag; alert is explicit and never masked by defaults.
Release gateSeed fixtures, permission matrix, migration review, rollback and manual fallback tested before branch pilot.
