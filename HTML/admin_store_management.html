Quy trình backup an toànSafe backup procedure

Trong ứng dụng desktop thật: người có quyền settings.manage chọn thư mục backup, tạo bản SQLite theo yêu cầu, kiểm tra file và lưu bản sao ngoài máy. Giao diện hiện không có restore; hãy diễn tập phục hồi bằng quy trình đã phê duyệt.In the real desktop app: a settings.manage user selects a backup directory, creates an on-demand SQLite copy, verifies it and keeps an off-device copy. There is no restore UI; rehearse recovery using an approved procedure.
